Features

置いて、眺めて、いつでも。Drop it. See it. Anytime.

ブラウザでもエクスプローラーでも、見つけたものはそのままドラッグ。キャンバスの上でバブルになって、いつでも取り出せます。Drag anything from your browser or Explorer. It becomes a bubble on the canvas, ready whenever you need it.

なんでもドラッグ＆ドロップDrag and drop anything

ローカルの画像や動画はもちろん、Web の画像・動画・ページのリンク、フォルダやアプリまで。置いたものはガラスのバブルとして並びます。Local images and videos, web images, videos and links, even folders and apps. Everything you drop lines up as a glass bubble.

画像動画Web リンクフォルダアプリ ImagesVideosLinksFoldersApps

キャンバスの上でそのまま再生Play videos right on the canvas

動画はクリックで再生。複数の動画を同時に流せるので、参考映像を並べて見比べるのにも向いています。ダブルクリックで、そのバブルだけを大きく表示します。Click a video to play it. Several can play at once, so you can compare references side by side. Double-click to bring one bubble up full size.

ほかのアプリへドラッグで戻すDrag back out to other apps

置いておいたバブルは、動画編集ソフトのタイムラインや 3D ソフトのビューポートへそのままドラッグできます。素材の置き場と作業場を行き来するのがぐっと楽になります。Drag a bubble straight into a video editor's timeline or a 3D app's viewport. Moving between your stash and your work gets much easier.

いつでも呼び出せるAlways one shortcut away

Windows の起動と一緒にトレイへ常駐。好きなショートカットキーで、作業中のどこからでもすぐに開けます。たくさん置いても、ズームで全体を見渡せます。Starts with Windows and waits in the tray. Open it from anywhere with the shortcut you choose, and zoom out to see everything at once.

例：e.g. Ctrl+Shift+Space

リスト再生List playback

置いた動画と同じフォルダにある動画や、プラグインから追加したメディアを一覧で表示。リストから選んで、そのまま次々と再生できます。Show the other videos in the same folder as the one you dropped, or media added from a plugin, as a list. Pick from it and keep playing one after another.

プラグインで広げるExtend it with plugins

標準では対応していない動画サービスやメディア、新しい機能をプラグインで追加できます。Add video services, media types and features that aren't supported out of the box with plugins.

Q&A

よくある質問Questions

無料で使えますか？Is it free?

はい、すべての機能を無料で使えます。ソースコードも MIT ライセンスで GitHub に公開しています。Yes. Every feature is free, and the source code is on GitHub under the MIT License.

Microsoft Store 版とインストーラ版の違いは？Store version or installer?

中身は同じです。Store 版は自動でアップデートされます。インストーラ版は GitHub の Releases から PocketBoardSetup.exe をダウンロードして入れます。They are the same app. The Store version updates itself; the installer (PocketBoardSetup.exe) is on the GitHub Releases page.

どんな OS で使えますか？Which OS does it run on?

Windows 用のアプリです（動作確認は Windows 11）。Mac と Linux 版はありません。It is a Windows app (tested on Windows 11). There are no Mac or Linux versions.

どんなものを置けますか？What can I put on it?

パソコンの動画・画像、Web の画像・動画・ページのリンク、フォルダやアプリまで置けます。動画はいくつでも同時に再生できます。Local videos and images, web images, videos and page links, even folders and apps. Several videos can play at once.

呼び出すショートカットは変えられますか？Can I change the shortcut?

はい。設定で好きなキーの組み合わせに変えられます。Yes. You can set any key combination in Settings.

対応していない動画サイトや機能を足したいCan I add services or features?

プラグインで追加できます。入れ方と作り方は プラグインガイド にまとめています。Yes, with plugins. See the plugin guide for how to install and build them.
